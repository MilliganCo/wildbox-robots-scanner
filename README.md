# Wildbox Robots Scanner

## Описание

Исследовательский скрипт для поиска доступных `robots.txt` на поддоменах `wildbox.ru`. Проект собирает хосты из открытых источников, затем асинхронно проверяет `http` и `https` адреса с ограничением по параллелизму и записывает краткий лог найденных ответов.

## Что делает

- собирает поддомены через `crt.sh`
- умеет дополнительно использовать `bufferover.run` и `RapidDNS`
- поддерживает опциональный поиск через `Censys`, если ключи заданы в переменных окружения
- отправляет `HEAD`, а затем `GET` к `/robots.txt`
- сохраняет технический лог проверки

## Стек

- Python 3.9+
- aiohttp
- asyncio

## Статус

WIP / исследовательский инструмент. Скрипт заточен под узкую задачу инвентаризации поддоменов и анализа доступности `robots.txt`.

## Как запустить

```bash
pip install -U aiohttp
python jll.py
```

При необходимости можно заранее выставить переменные окружения `CENSYS_API_ID` и `CENSYS_API_SECRET`.

## Примечание

В репозиторий не включаются временные логи и локальные артефакты запуска.
